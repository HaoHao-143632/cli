# 母乳喂养科普视频脚本 & PPT

妇产科健康科普素材包,面向**孕产妇及家属**,可用于科室宣教、孕妇学校、公众号短视频等。

## 文件清单

| 文件 | 说明 |
|------|------|
| `母乳喂养科普视频脚本.md` | 完整视频解说脚本(15 个分镜:画面 / 解说词 / 字幕 / 时长 + 制作备注) |
| `母乳喂养科普.pptx` | 配套 PPT(15 张,16:9,暖色系;**解说词已写入每页“演讲者备注”**) |
| `generate_ppt.py` | PPT 生成脚本,可修改文案后重新生成 |

## 内容大纲

1. 封面
2. WHO 喂养建议 · 本期内容
3. 母乳对宝宝的好处
4. 母乳对妈妈的好处
5. 初乳:第一剂“天然疫苗”
6. “三早”原则
7. 正确的哺乳姿势
8. 正确含接(衔乳)要点
9. 按需哺乳:读懂饥饿信号
10. 怎么判断宝宝吃饱了
11. 常见问题与对策
12. 哺乳期妈妈的饮食与生活
13. 母乳的挤出与储存(含时间表)
14. 常见误区辟谣
15. 结尾:科学喂养 · 温暖陪伴

## 如何修改并重新生成 PPT

```bash
pip install python-pptx
python generate_ppt.py   # 生成 母乳喂养科普.pptx
```

修改 `generate_ppt.py` 中 `build()` 函数里的文案即可。配色在文件顶部 `PRIMARY / SECONDARY / ACCENT` 处统一调整。

## 录制配音建议

- 打开 PPT 后,在“演讲者备注”中可直接看到每页解说词。
- 字体使用「微软雅黑」,若展示设备缺失会自动回退,建议放映前确认。
- 片尾第 15 页请替换为本科室的**名称、咨询电话、母乳喂养门诊二维码**。

## 合规提示

本素材为**健康科普**,不替代医生面诊。涉及具体用药、疾病处理处,统一以“具体请遵医嘱”为准。正式发布前,建议核对最新版《婴幼儿喂养指南》等权威资料中的数据。
