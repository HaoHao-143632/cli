# 飞机大战 / Airplane Shooter 🚀

一个纯原生 HTML5 + Canvas + JavaScript 编写的打飞机小游戏，**零依赖**，打开即玩。

## 如何运行

直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：双击 index.html

# 方式二：本地起一个静态服务器（推荐，避免某些浏览器限制）
cd games/airplane-shooter
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 `←↑↓→` 或 `WASD` |
| 移动（触屏/鼠标）| 直接拖动飞机 |
| 开火 | **自动开火**，无需按键 |
| 暂停 / 继续 | `P` |

支持电脑与手机（触摸拖动控制）。

## 玩法

- **自动射击**，专注走位躲避敌机与敌方子弹。
- 击落敌机得分，敌机分三种：
  - 🔴 小兵：速度快、一击毙命
  - 🟠 普通：血量中等
  - 🟣 精英：血厚、会射击、掉落道具概率高
- 拾取道具升级：
  - ⚡ 火力 +1（最高 5 级，弹幕更密）
  - ♥ 生命 +1（最高 5 条）
- 被撞 / 中弹会损失 1 条命并降一级火力，随后短暂无敌。
- 随时间推移敌机刷新越来越快，挑战你的最高分（本地保存）。

## 技术

- 单文件无构建：`index.html` + `game.js`
- `requestAnimationFrame` 游戏主循环
- DPR 自适应高清渲染，按窗口比例缩放
- 粒子爆炸、屏幕抖动、星空背景等手感细节
- 最高分通过 `localStorage` 持久化
