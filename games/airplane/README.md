# 飞机大战 (Airplane Shooter)

一个使用 HTML5 Canvas 和原生 JavaScript 编写的经典飞机射击游戏，无需任何依赖，在浏览器中直接运行。

## 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏：

```bash
# macOS
open index.html

# Linux
xdg-open index.html
```

## 操作说明

- **方向键 / WASD**：移动飞机
- **空格键**：发射子弹
- **P 键**：暂停 / 继续

## 游戏特性

- 三种敌机类型：
  - **红色小兵**：血量低、速度快
  - **橙色射手**：会向玩家射击
  - **紫色坦克**：血量高、速度慢、得分高
- 随得分提升的等级系统，等级越高敌机越多越快
- 等级 3 开始自动解锁三连射
- 受击无敌时间、粒子爆炸特效、滚动星空背景
- 生命值、暂停、重新开始等完整游戏循环
