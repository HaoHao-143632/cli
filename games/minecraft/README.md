# 我的世界 · Mini Craft 🧱

一个纯浏览器、单文件的体素（Voxel）小游戏，灵感来自《我的世界》(Minecraft)。
使用 [Three.js](https://threejs.org/) 实现，无需构建、无需后端，打开即玩。

![type](https://img.shields.io/badge/engine-Three.js-orange) ![deps](https://img.shields.io/badge/dependencies-none-green)

## ✨ 功能特性

- **程序生成地形**：基于值噪声生成起伏的山丘、草地、沙滩，并随机种树。
- **破坏与放置**：左键破坏方块，右键放置方块，自由建造。
- **8 种方块**：草方块、泥土、石头、木头、树叶、沙子、砖块、玻璃（半透明）。
- **第一人称控制**：鼠标视角 + WASD 移动 + 跳跃，带重力与 AABB 碰撞。
- **飞行模式**：按 `F` 一键切换创造式飞行。
- **性能优化**：逐面剔除（只渲染暴露的面）+ 透明/不透明分组渲染。
- **音效**：用 Web Audio 实时合成破坏、放置、跳跃、脚步声（无需音频文件），右上角 🔊 或按 `M` 静音。
- **HUD**：实时坐标、朝向、方块数量、FPS。

## 🎮 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 前后左右移动 |
| `空格` | 跳跃（飞行时上升）|
| `Shift` | 飞行时下降 |
| `鼠标移动` | 转动视角 |
| `鼠标左键` | 破坏方块 |
| `鼠标右键` | 放置方块 |
| `1` ~ `8` / `滚轮` | 选择方块类型 |
| `F` | 切换飞行模式 |
| `M` | 静音 / 取消静音 |
| `ESC` | 释放鼠标指针 |

## 📱 在手机上玩

游戏已完整适配触屏。在手机浏览器中打开后点「开始游戏」即可，操作方式：

- **左下虚拟摇杆** —— 移动
- **拖动右侧屏幕** —— 转动视角（准星始终在屏幕中心）
- **右下按钮** —— 破坏 / 放置 / 跳跃 / 飞行
- **底部物品栏** —— 点击切换方块

### 让手机能直接打开链接（GitHub Pages）

仓库内置了 `.github/workflows/deploy-game.yml`，会把本游戏发布到 GitHub Pages。
**首次启用一次即可**：

1. 打开仓库 **Settings → Pages**
2. **Build and deployment → Source** 选择 **GitHub Actions**
3. 推送到 `main`（或本功能分支）后，工作流会自动部署
4. 部署完成后，手机浏览器访问 `https://<用户名>.github.io/cli/` 即可游玩

> 也可以在电脑上启动本地服务器（见下方），手机连同一 Wi-Fi 后访问
> `http://<电脑局域网IP>:8000`。

## 🚀 运行方法

由于使用了 ES 模块和 importmap，需要通过 HTTP 服务器打开（不能直接双击 `index.html`）。

任选其一：

```bash
# 方法 1：Python（大多数系统自带）
cd games/minecraft
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000

# 方法 2：Node.js
cd games/minecraft
npx serve .

# 方法 3：任意静态服务器
```

然后在浏览器访问对应地址，点击「开始游戏」即可。

## 🛠 技术细节

- **世界存储**：一维 `Uint8Array`，`0` 表示空气，其余为方块 ID。
- **地形**：哈希值噪声 + 双线性平滑插值，叠加两层频率制造细节。
- **网格构建**：遍历体素，仅当邻居为空气（或透明）时生成该面，大幅减少三角形。
- **射线检测**：DDA 体素遍历算法，精确选中准星指向的方块及其面法线。
- **碰撞**：分轴推进的 AABB 碰撞检测，支持跳跃落地判定。
