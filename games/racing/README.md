# 极品飞车 · Need for Speed Clone

一个纯 HTML5 Canvas + JavaScript 的霓虹风格街机赛车小游戏，无任何依赖、无需构建，浏览器打开 `index.html` 即可游玩。

## 玩法

| 操作       | 按键                                   |
| ---------- | -------------------------------------- |
| 左右变道   | `←` `→` 或 `A` `D`                     |
| 加速 / 刹车| `↑` `W` / `↓` `S`                      |
| 氮气加速   | `Shift` 或 `空格`（消耗能量条，自动恢复） |
| 暂停       | `P`                                    |
| 重新开始   | `R`                                    |

- 4 车道无尽道路，超车 +10 分，速度本身持续累计积分
- 距离越远，敌车出现越密集、速度越快
- 撞车即结束，最高分会保存在浏览器 `localStorage`

## 特性

- 程序化生成的音频（引擎、爆炸、提示音），无外部资源
- 视差城市天际线 + 霓虹道路 + 头灯光束
- 屏幕震动、爆炸粒子、氮气尾焰
- 单文件、零依赖、零构建

## 运行

直接双击 `index.html`，或：

```bash
python3 -m http.server -d games/racing 8000
# 然后访问 http://localhost:8000
```
