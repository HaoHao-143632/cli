# English Fun · 英语练习乐园 🌟

一个面向 **初学者 / 中小学生** 的英语练习网站。纯静态前端，**双击 `index.html` 即可在浏览器打开使用**，无需安装、无需后端。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 🃏 单词卡片 | 按主题分类（动物 / 食物 / 颜色 / 学校）记单词，点击卡片翻面看中文 + 例句，点喇叭跟读 |
| ✏️ 语法练习 | 选择题，答题后立即显示中文解析，随机抽题 |
| 🎧 听力练习 | 用浏览器语音合成朗读英文句子，选出听到的内容（可重复播放） |
| 📖 阅读理解 | 短文阅读 + 理解题，可朗读全文，完成后自动进入下一篇 |

学习进度（练习次数、正确率、答题总数）通过浏览器 `localStorage` 自动保存在本机。

## 使用方法

直接打开 `index.html` 即可。若要通过本地服务器预览（部分浏览器对 `file://` 限制较多时推荐）：

```bash
cd web/english-practice
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

> 听力 / 跟读功能依赖浏览器的 Web Speech API，建议使用 **Chrome 或 Edge** 等现代浏览器，并确保系统已安装英文语音包。

## 自定义内容

所有题目和单词集中在 [`data/content.js`](data/content.js)，按注释格式增删即可，保存后刷新页面生效，**不需要重新构建**。

## 目录结构

```
web/english-practice/
├── index.html          # 页面结构
├── styles.css          # 样式
├── app.js              # 交互逻辑（无框架）
└── data/content.js     # 练习内容数据
```
