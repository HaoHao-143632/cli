# 杭州小学数学学习辅导网站(人教版 1–6 年级)

一个纯静态的小学数学学习辅导网站,内容与**人教版(PEP)**教材同步,覆盖一年级到六年级、上下册的核心知识点,并为绝大多数单元配备**随机生成的互动练习题**(即时批改、答案提示)。

## 功能

- **年级 → 单元 → 知识点**:按人教版课本章节顺序组织,清晰列出每个单元的核心知识点。
- **互动练习**:每个单元配有题目生成器,题目随机生成、可无限刷,涵盖加减乘除、分数、小数、面积体积、方程、比例、百分数等。
- **即时批改 + 提示**:答题后立即判断对错,答错给出正确答案;部分题目提供解题提示。
- **响应式设计**:手机、平板、电脑均可使用。
- **零依赖**:纯 HTML/CSS/原生 JavaScript,无需构建、无需联网。

## 目录结构

```
web/
├── index.html          # 页面入口
├── css/style.css       # 样式
└── js/
    ├── curriculum.js   # 人教版课程数据(年级/单元/知识点)
    └── app.js          # 导航、练习生成与判分逻辑
```

## 直接打开就能用(推荐)

下载 **`杭州小学数学辅导.html`** 这一个文件,双击用浏览器打开即可使用——所有样式和脚本都已内嵌,无需文件夹、无需联网、无需任何环境。

## 本地运行(分文件版本)

也可以直接用浏览器打开 `index.html`(同目录需保留 `css/`、`js/`);或启动一个简单的本地服务器:

```bash
cd web
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 如何扩展

- **新增/修改知识点**:编辑 `js/curriculum.js`,在对应年级的 `units` 里增删条目。
- **新增题型**:在 `js/app.js` 的 `GENERATORS` 中新增一个函数(返回 `{ q, a, hint? }`),再把该函数名填到课程数据对应单元的 `skill` 字段即可。

> 说明:本站为学习练习用途,教材版本为人教版(PEP)。
