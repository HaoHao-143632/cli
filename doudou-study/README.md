# 🌱 豆豆学习监督台

一个帮助家长**监督、辅导豆豆每天学习**的小网站。纯前端实现,**双击 `index.html` 即可在浏览器打开使用**,不需要安装、不需要联网、不需要后端。所有数据保存在本机浏览器(localStorage),不会上传到任何服务器。

## 功能一览

| 模块 | 说明 |
| --- | --- |
| 📊 **仪表盘** | 今日任务完成度、学习时长、连续打卡、每日鼓励语、每日打卡(连续 7 天额外奖励) |
| ✅ **作业任务** | 按学科添加作业/任务,完成打勾得积分,可按学科筛选 |
| ⏱️ **番茄钟** | 15/25/40 分钟专注计时,完成自动记录时长并奖励积分 |
| 📅 **周计划** | 一周 × 多时段的学习计划表,点格子填写、自动保存 |
| 📕 **错题本** | 记录错题、知识点与订正笔记,标记"已掌握"得积分 |
| 🎁 **积分奖励** | 自定义奖励商店(如"看 30 分钟动画片"),用积分兑换,含积分流水 |
| 📈 **学习统计** | 最近 7 天学习时长柱状图、各学科完成任务数、累计数据 |

## 积分规则(可在代码中调整)

- 每日打卡:**+5**,连续满 7 天额外 **+20**
- 完成一个番茄钟:**+8**
- 完成一个任务:**+5 ~ +20**(添加时可选)
- 掌握一道错题:**+5**
- 兑换奖励:扣除对应积分

## 使用方法

1. 下载 `doudou-study` 文件夹。
2. 双击 `index.html`,用任意现代浏览器(Chrome / Edge / Safari)打开。
3. 给豆豆安排今天的任务,开始学习并打卡。

> 想换孩子名字或调整积分、每日目标,编辑 `assets/app.js` 顶部的常量即可。
