# 学习时间提醒 APP

一个简洁的网页版学习番茄钟，专为帮助你集中精力学习而设计。打开 `index.html` 即可使用，无需安装任何依赖。

## 功能

- ⏱ **番茄工作法**：专注 / 短休息 / 长休息 三种模式自由切换
- 🎯 **自定义时长**：专注、休息时长以及长休息间隔均可调整
- 🔔 **三重提醒**：桌面通知 + 声音提示 + 页面 Toast 三重提醒不错过
- 📊 **每日统计**：自动记录今日完成的专注时段、累计学习分钟数和学习内容
- 💾 **本地保存**：所有数据保存在浏览器 localStorage，无需登录、无需联网
- ⌨️ **快捷键**：`空格` 开始/暂停，`R` 重置
- 🌗 **明暗主题**：根据系统主题自动切换

## 使用方法

1. 在浏览器中打开 `study-reminder/index.html`
2. 在「当前学习内容」中填写正在学习的科目（可选）
3. 点击「开始」启动专注计时
4. 计时结束后会自动进入休息时段（可在设置中关闭自动开始）
