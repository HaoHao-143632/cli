# 🌈 小小学习管家

> 一个专为小学生设计的每天回家学习时间提醒 Web App,儿童友好的界面,无需安装。

## ✨ 功能特点

- 📅 **今日学习** — 一目了然的今日任务列表,完成进度可视化
- ⏰ **学习提醒** — 到点自动弹窗 + 浏览器通知 + 提示音
- 🍅 **专注番茄钟** — 25 分钟专注 + 5 分钟休息,时长可调
- 📚 **学习计划** — 自定义科目与时间,内置推荐时间表一键加载
- 🏆 **奖励系统** — 每完成任务获得星星 ⭐,解锁 6 种成就勋章
- 🔥 **连续打卡** — 培养每日学习好习惯
- 📊 **每周统计** — 最近 7 天学习情况柱状图
- 💾 **本地存储** — 数据保存在浏览器本地,隐私安全
- 📱 **响应式** — 电脑、平板、手机都能用

## 🚀 使用方法

### 方式一:直接打开
双击 `index.html` 即可在浏览器中打开使用。

### 方式二:本地服务器(推荐,通知功能更稳定)
```bash
cd study-reminder-app
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

## 👶 给家长的话

1. 让孩子先进入 **设置 ⚙️** 填写自己的昵称
2. 开启 **浏览器通知**(首次会弹出权限申请,请点击"允许")
3. 在 **我的计划 📚** 中点击 **一键加载推荐计划** 或自行添加任务
4. 每天回家后打开应用,准时提醒孩子学习
5. 完成任务和番茄钟会获得星星和勋章奖励,激励孩子坚持

## 🏗️ 技术栈

- 纯 HTML + CSS + JavaScript,**零依赖**
- localStorage 持久化数据
- Web Notifications API 通知
- Web Audio API 提示音
